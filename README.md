# DevaCore Studio

A responsive, dark-first studio website for DevaCore Studio.

## Included
- Responsive navigation and hero section
- Futuristic CSS motion graphic (no external image asset required)
- Service cards for web, app, game, branding, video and digital consulting
- Download hub with Mobile Apps and Software tabs
- Download entries intentionally show **Coming Soon** until official release URLs, versions and verified installers are supplied
- Filterable portfolio showcasing DevaCore ecosystem projects
- About / trust section, contact CTA, social links
- Privacy Policy and Terms & Conditions pages

## Deploy
This is a static website. Publish the repository root with GitHub Pages or configure a static-site host with:
- Build command: none
- Publish directory: repository root
- Entry file: `index.html`

## Before launch
- Replace placeholder social profile URLs with official DevaCore accounts.
- Confirm the official contact email and replace `hello@devacore.studio` if needed.
- Add verified APK / EXE / DMG URLs, release versions, checksums and system requirements before enabling downloads.
- Add real project screenshots and case-study links as available.

No download button points to a fake or unverified file.
